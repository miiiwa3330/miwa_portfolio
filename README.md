# Miiiwa Portfolio

駆け出し学生エンジニア（27卒）「Miiiwa」のポートフォリオサイトです。
「面白いを最優先！」をモットーに、技術力とデザイン性、そして遊び心を詰め込んだWebアプリケーションです。

## 🌐 サイトの特長
- **部屋の中を見渡す3D**: トップページはHTMLではなく、Three.js で描いた**ロケットを増改築したコロニーの中の、円い自分の部屋**。部屋の中央に立って首を振り、5つの区画（ホログラム＝自己紹介、展示棚＝制作実績、技術書の本棚＝技術スタック、調査ボード＝経歴・活動、通信端末＝お問い合わせ）とデスクトップPCを見て回ります。外部の3Dモデルも画像も使わず、家具も壁の錆も窓の外の街もコードで手続き的に生成しています。
- **見回し方**: スクロールすると右へ首を振って区画を順に巡ります。PC では部屋を1回クリックするとマウスが視点になり、FPS ゲームのように動かした方を向きます（照準を稲妻のマーカーに合わせてクリックすると寄れます。Esc でカーソルが戻ります）。スマホではドラッグで見回せます（どちらも向けた向きのまま留まります）。部屋は勝手には回らず、ゲームの一人称視点のように、立っているあいだも視界がわずかに揺れます。区画の上の稲妻のマーカー（またはカードの「詳しく見る」）を押すと、その物の前へ寄って詳細ページが開きます。視点は 魚眼（樽型、部屋を広く見渡す）→ 標準 → ズーム（正面の物へ寄る）の3段で、PC ではヘッダーのズームボタン、スマホでは2本指ピンチ（魚眼↔標準）で切り替えます。
- **PCを操作する**: 机のPCに寄ると（マーカー、ズーム、または `/#desk`）椅子に座り、画面の中のデスクトップを操作できます。ファイルを開くと、自己紹介・制作実績・技術スタック・経歴・お問い合わせ・ノートをPCの画面の中で読めます。GitHub・X・ターミナルモードもここから開けます。座っているあいだは、画面の外で2本指でスワイプすると机の4つの画面（左の Macintosh・正面のメイン・右の縦置き・上の監視カメラ）へ向けます。左の Macintosh 128K では Snake・Breakout・Mines が遊べます（アイコンをダブルクリック、Esc かウィンドウのクローズボックスで終了）。Snake は W/A/S/D か矢印キー、Breakout は Mac のマウスか A/D、Mines はクリック（⌘ か Option を押しながらで旗）。
- **ホログラムの自己紹介**: 自己紹介に寄ると、机の上のデバイスから出たホログラムに自己紹介の文字が流れます。放っておいても進み、ホイールで加速・逆走もできます。最後まで読むと部屋の中央へ戻ります。
- **照明を操作する**: 天井灯とデスクライトの入切、ネオンの色の切り替えを、扉の脇のスイッチ（部屋の中の物を直接押す）かヘッダーの照明ボタンからできます。
- **歩いて跳べる**: PC では W/A/S/D で部屋の中を歩き、Space で跳べます（壁と家具では止まります）。
- **自分の部屋**: 見ているあなたは部屋の主の目を通して部屋を見ています。机のホログラムには、あなた自身が光の姿で映って回っています。部屋の主は黒髪に細い黒縁の眼鏡、黒い T シャツとワイドなカーゴパンツの青年（168cm、キャラクターシートから寸法を測ってコードで組んだ形）です。下を向くと自分の体が、右のモニターには天井の監視カメラに映る自分が、経歴・活動の看板の右上のカーブミラーには部屋ごと映る自分が見えます。区画を選ぶとそこまで歩いて行き、PC では椅子を引いて座ってから、椅子ごと机へ寄ります。上の段のモニターのアームから吊ったホログラムファンには、あなたの端末の時刻が立体の数字で浮かび、羽が回っています。
- **ハイブリッド・レイアウト**: 3Dシーンを背面に固定し、その上に通常のHTMLで組んだ詳細ページをオーバーレイ。PCの画面とホログラムの文字も、部屋の中に置いた本物のHTMLです。3Dの没入感とWebサイトとしての読みやすさを両立させています。
- **カードでエリアを送る**: カードは、いま正面にある区画の紹介。PC では画面左に重なって並び、カーソルを乗せて上下にスクロールすると次のカードへ切り替わります。スマホでは画面下のレールになり、横にスワイプすると隣の区画へ送れます。どちらも部屋の中で首を振ってその区画を正面に連れてきます。
- **多言語対応**: ヘッダーのトグルで日本語 / 英語を切り替えできます。
- **停止・再生**: 部屋の動き（視界の揺れ・ホログラム・モニターの動画）を押した瞬間に止められます。PC では言語トグルの右のボタン、**スマホでは何もないところを軽くタップ**（動画プレイヤーのような再生／停止のマークが一瞬出ます）。止めている間も自分で見回して眺める角度は変えられ、再生すると止めたところから続きます。
- **スマホ専用の組み替え**: `lg` 未満のタッチ画面では、ボタンを減らして指の操作に置き換えています。停止はタップ、ズームはピンチ、セクション一覧は全画面のメニュー、カードは画面下のレール。ノッチとホームインジケータも避けます。PC のレイアウトはそのままです（ただし幅 1280px 未満のウィンドウでは、ヘッダーのナビがメニューボタンにまとまります）。
- **経歴から制作実績へ**: 経歴・活動のタイムラインのうち、サービスの開発や公開にあたる項目はタップでき、制作実績に切り替わってそのサービスの紹介が開きます。紹介の「Play」からサービス本体へ進めます。
- **制作実績の紹介ページ**: 制作実績のポップアップの「Read More」から、プロダクトごとの紹介ページ（`/products/<slug>`）へ進めます。何を作ったのか、なぜ作ったのか、中身はどうなっているのかを1ページずつ読み物として書いています。先頭と末尾の「Play Now」からサービス本体へ。一覧は `/products`。見た目はハブの詳細シート（制作実績のカードやポップアップ）と同じです。
- **ノート**: 作りながら考えたこと・つまずいたことを書く技術日記（`/notes`）。ヘッダーのナビの右端、「｜」で区切った「ノート」から開きます（部屋の区画ではなく、普通のページへのリンク）。PCの「ノート」のファイルからも一覧を見られます。
- **過去のバージョンに触れる**: 制作実績には、このサイト自身の過去の版も並んでいます。初代の v0（ダーク／ネオンの1ページサイト）と、2代目の v1（宇宙に浮かぶボクセルの惑星）です。スクリーンショットではなく当時のビルドをそのまま同居させているので、「Play」から当時の画面を実際に操作できます。
- **静的エクスポート対応**: `output: 'export'` による完全な静的サイトとしてビルドされ、Cloudflare Pagesなどへ高速デプロイが可能。

## 💻 ターミナルモード (Easter Egg)
本ポートフォリオには、遊び心として**インタラクティブなターミナルモード**が隠されています。

### 起動方法
PC では画面左下のPCアイコンをクリックしてリンク群を開き、その中の `[>_]` ターミナルアイコンをクリックしてください。部屋の机のPCに座って、デスクトップの「ターミナル」を開いても起動します。スマホではヘッダーのメニューを開くと、下部にリンク群と一緒に並んでいます。
ハッカー風の起動シークエンスの後、本物のコマンドラインのように操作できる画面が開きます。

### 使えるコマンド一覧
ターミナル内では以下のUNIX風コマンドが使用可能です。

- `ls` : 現在のディレクトリにあるファイル一覧を表示 (`README.md`, `about.txt` など)
- `cd <dir>` : ディレクトリを移動 (例: `cd products`)
- `pwd` : 現在のディレクトリパスを表示
- `cat <file>` : ファイルの中身をアスキーアートと共に表示 (例: `cat about.txt`)
- `date` : 現在のシステム時刻を表示
- `whoami` : 現在のログインユーザーを表示
- `clear` : 画面のログを消去
- `exit` : ターミナルモードを終了し、通常の画面に戻る

**ショートカットコマンド**
ファイル名を指定せずに、単に `about`, `skills`, `experience`, `products` と入力するだけでも情報が閲覧できます。
もちろん `help` コマンドでいつでも使い方を確認できます。

## 🚀 開発環境の立ち上げ

1. パッケージのインストール:
   ```bash
   npm install
   ```
2. 開発用サーバーの起動:
   ```bash
   npm run dev
   ```
3. ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスして確認してください。

## 📦 ビルドとデプロイ

Cloudflare Pages や Vercel などに静的デプロイを行う場合:

```bash
npm run build
```

ビルドが成功すると、ルートディレクトリに `out/` フォルダが生成されます。このフォルダの静的ファイルをホスティングサービスにアップロードしてください。

## 📁 ディレクトリ構成

画面上の役割でディレクトリを切っている（`components/` のような実装手段での分類はしていない）。

```
src/
├── app/                   # App Router のエントリポイント（layout / page / globals.css / アイコン）
│   └── (reading)/         #   読み物のページ（制作実績の一覧と個別ページ、ノートの一覧と個別ページ）
├── mdx-components.tsx     # 読み物の本文（MDX）の型
├── content/               # 読み物の本文（products/<slug>.mdx・notes/<slug>.mdx）
├── reading/               # 読み物のページの部品（ヘッダー・フッター・一覧・メタデータ）。見た目の部品は hub/・detail/ のものを使う
├── types.ts               # 全層が読む語彙（Language / SectionType / Stop / Focus）
├── state/                 # アプリ全体の状態（AppState / Language の Context、URLハッシュ連携、スマホ判定）
├── scene/                 # Three.js / R3F のシーン
│   ├── Scene.tsx          #   キャンバスとカメラの制御（行き先を決める effect はここ1つだけ）
│   ├── LensRenderer.tsx   #   描画（通常の遠近と、魚眼の立方体）
│   ├── camera/            #   姿勢・飛行・レンズ・画面への射影・HTMLを3Dに置くCSSの計算
│   ├── room/              #   部屋の配置・巡回・HTMLの板・照明・体の関節の純粋関数
│   ├── mac/               #   Macintosh が動かすもの（デスクトップと Snake・Breakout・Mines・音）の純粋関数と状態
│   └── objects/           #   シーンに置かれるもの（部屋と家具・マーカー・体・監視カメラ・テクスチャ）
├── lab/                   # 部屋の部品を1つずつ見る開発用のページ（`/lab`。開発のときだけ存在し、本番のビルドには出ない）
├── hub/                   # キャンバスの上に浮くホーム画面（PC の枠組みとスマホの全画面メニュー）
│   ├── card/              #   エリアカード（PC のスタックとスマホの下部レール）と、マーカーへ伸びる稲妻の点線
│   ├── room/              #   部屋の中に置くHTMLの層
│   ├── desk/              #   PCの画面のGUI
│   └── about/             #   自己紹介の文とホログラム
├── detail/                # HTMLで組む詳細ページの各セクション
│   └── products/          #   制作実績セクションのUI
├── terminal/              # ターミナルモード（Context + Overlay）
├── ui/                    # 複数箇所で使う共有UIパーツ（アイコン・ロゴ等）
└── data/                  # 制作実績と経歴のデータ（日英）、ノートの登録簿、サイトの URL
```

技術スタックの詳細は [docs/tech.md](docs/tech.md)、配置と命名の規約は [docs/structure.md](docs/structure.md) を参照してください。ドキュメント全体の地図は [docs/README.md](docs/README.md) にあります。
