## 日用品をモチーフにしたクッションブランドの公式サイト

GOTO（`goto-cushion.com`）は、日用品をモチーフにしたユニークな造形の大型クッションブランドのために受託制作した公式 Web サイトです。ラグジュアリーとストリートの空気感を掛け合わせ、写真と余白、そしてスクロールに連動した立体的な画面遷移を主役にして構成しています。

日本語と英語の両方に対応しており、初期表示は `/ja/` として、ヘッダーから同じページの別言語へそのまま切り替えられます。

## 映像からファーストビュー、セクションを横断する演出

サイト全体の体験で重視したのは、ページの区間どうしを「別々の画面」にせず、1 つの物体が空間を移動しながら場面をつなげていくことです。

- **イントロムービーとヒーローへの接続**: サイトを開くと全画面のブランドムービーが流れ、終盤で動画の枠が広がってファーストビューへとシームレスに移ります。ファーストビューには「常識を被るな（Do not wear the norm.）」のタイポグラフィと、キャップ型クッションをかぶった地球が浮かび、スクロール量に応じて文字が 1 字ずつせり上がってから動き出します
- **セクションを跨ぐモーフ遷移**: スクロールを進めると、ファーストビューにあったキャップが回転しながら About のモデル写真の位置へ飛び、続いて Gallery の先頭商品へと着地して横スクロールのギャラリーへつながります
- **ステッカーと商品詳細への View Transitions**: リンクやボタン以外の場所をクリック／タップすると、商品の切り抜き画像がステッカーとして画面に貼られていく遊び心を入れています。Collection から商品を押すと、ブラウザの View Transitions を使って、押した商品がそのまま商品詳細ページの黒いステージ上へ移動し、戻る操作では元の位置へ縮みながら戻ります

## ページ構成とカート機能

サイトはトップページ（Intro・Hero・About・Gallery・Collection・Craft・Contact）、商品詳細ページ（`/ja/products/<id>/`・`/en/products/<id>/`）、およびカート引き出し（PC は右側のドロワー、スマホは下からスワイプで引き出せるシート）で構成されています。

- **商品詳細と多色展開**: 5 色のバリエーションごとに独立したページを持ち、ほかの色への切り替えも View Transitions で同じステージ上で入れ替わります。商品ごとのタイトルや説明文はメタデータにも自動反映され、検索や SNS シェア時にも各商品のページとして認識されます
- **ローカル保存のカート**: カートに追加した商品と数量はお客さんのブラウザ（`localStorage`）に保存され、ページ移動や日英の言語切り替え、別タブ間でも状態が保たれます。販売開始前・価格未定のアイテムも含めて数量変更や削除の UI を確かめられるようにしています

## タイポグラフィと反転色ヘッダーのこだわり

ラグジュアリーとストリートの掛け合わせを表現するため、書体と配色の設計にも細かく手を入れました。背景には真っ黒（`#000`）と漆喰のような明るい灰色（`#eeebe5`）を交互に使い、商品を浮かせる台座を黒地に揃えることで、ファーストビューから商品詳細ページまで見た目の連続性を保っています。

- **見出しと書体の使い分け**: セクション見出しには力強い幅広ゴシックの Unbounded、本文には Inter と端末の和文ゴシックを採用し、ブランド名の `GOTO` には幾何学的な League Spartan を当てています
- **背景と反転するヘッダー**: 画面上部に固定したヘッダーや右下のカートボタンには `mix-blend-difference` を使い、明るい区間の上を通っても黒い区間の上を通っても視認性を保てるようにしました

## 技術構成と公開基盤

見せる体験の軽さとアニメーションの滑らかさを両立するため、Astro と Cloudflare Workers を中心に設計しました。

- **Astro 7 + Cloudflare Workers**: 全ページを事前に HTML としてビルドして配信し、動きの必要な部分だけに JavaScript を読み込ませています
- **GSAP + Lenis + View Transitions**: スクロール連動の固定・文字分割アニメーションは GSAP、慣性スクロールは Lenis で実装しました。ただし、ページ区間のピン留め（`ScrollTrigger` の pin）がページの縦の長さを伸ばすため、別のページから `#collection` などのアンカー付きで戻った際は、固定を作り終えてから Lenis の長さを測り直して正しい位置へスクロールし直す処理を入れています。ハッシュ移動はクリックを先取りする独自ハンドラに一本化し、ブラウザ標準の移動や慣性スクロールと打ち消し合わないようにしました
- **Range 配信対応のイントロ動画**: Safari（iPhone）では静的アセットが Range（部分読み込み）に応じないと動画再生が止まるため、Workers のエンドポイントから `206 Partial Content` で配信する仕組みを組み込んでいます。さらに再生開始の自動再生制限に備え、音声付き再生がブロックされた場合は自動でミュート再生へ切り替え、画面上のボタンから音を出せるようにしています
- **レスポンシブ設計**: スマートフォンでは「常識を／被るな」の 2 行レイアウトや画面の高さに応じた写真サイズの自動調整、右下のカートボタン、ハンバーガーメニューなど、片手操作と狭い画面での見え方に合わせた専用の余白設計を行っています
