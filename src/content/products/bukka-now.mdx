## あなたの物価感覚、いま合っていますか

お米5kgはいくらか。牛丼の並はいくらか。数年前なら即答できた値段が、いまは自信を持って言えなくなっています。値上げのニュースは毎週のように流れてくるのに、自分の頭の中の値札がどれくらい古くなっているのかは、確かめる方法がありません。

bukka_now（物価ナウ）は、それを数字で確かめるための Web サービスです。日用品・食料品・サービスの値段をテンキーで答えると、最後に「あなたの物価感覚は上位何%か」が出ます。会員登録もログインも要らず、開いたらすぐに始められます。

## 遊び方

トップ画面で出題数を選んでスタートします。出題数は10問から100問まで、10問刻みで選べます。

問題はすべて「〇〇はいくら？」の形で、答えはすべて金額（円）です。選択肢もスライダーもありません。画面のテンキー（PC なら物理キーボードの数字キーと Enter）で、思った値段をそのまま打ち込みます。最初の設計では4択・スライダー・過去の値段との比較を組み合わせたクイズにしていましたが、作りながら**電卓のようにじかに数字を打つ形だけ**に絞りました。

1問の制限時間は10秒です。残り3秒を切るとゲージが赤く点滅し、0秒になったらその時点の入力で自動的に確定します。スマホでも、問題文からテンキーと決定ボタンまでがスクロールせずに1画面に収まるように詰めてあります。10秒しかないのに、決定ボタンを探してスクロールさせるわけにはいかないからです。

## 正解はどこから来ているか

正解の値段は、総務省統計局の「小売物価統計調査」の公表値です。出題プールは100問あり、正解は東京都区部の2025年の年平均価格です（郵便料金や映画のように全国で同じ値段のものは全国統一価格）。

統計で確かめられない値段、たとえば特定のチェーン店のメニュー価格は出題していません。「正解」に根拠がないクイズは、外れたときに納得できないからです。

聞き方にも気を配りました。統計の元データは「1kgあたり」のような業者向けの単位で書かれていることがありますが、出題は「もやし1袋（200g）」「卵（10個入りパック）」「豚肉100g」のように、**普段お店の値札で見ている単位**に直しています。設問の下には「東京都区部・2025年平均」と、地域・年・出典を必ず出しています。

## 採点のしかた

1問ごとの点数は、答えと正解の**比**で決めています。正解ちょうどで100点、正解の3倍または3分の1で0点です。たとえば正解が1,000円の問題に800円と答えると80点、1,500円と答えると63点になります。

最初は「正解から40%ずれたら0点」という式でした。ところが実際に遊んでもらった回答11件で採点すると、平均が23点で、6件が0点。誰がやってもほぼ0点では、診断になりません。5つの式を比べて、同じ11件で平均52点・0点が1件になり、それでいて人による相場観の差も点数に残る、今の式を選びました。

比を対数で扱うので、**高く見積もりすぎた人と安く見積もりすぎた人を同じ厳しさで採点**できます。2倍と答えた人と半分と答えた人は、同じ点数になります。

全問の平均が総合スコアになり、それをこれまでの全員の総合スコアと並べて「上位何%」を出します。さらに、総合スコアと「安く見積もりがちか、高く見積もりがちか」の傾向から、「リアルタイム相場マスター」「過去価格タイムスリップ型」「インフレ過敏型」「大らか直感型」の4つのタイプに分けます。スコア帯ごとに少し辛口のコメントも用意していて、100点と0点の特別枠を含めて22段階あります。

## 結果画面の3つの面

結果画面の上にはスコアのカードを固定し、その下に横にスライドする3つの面を置いています。

- **回答分布**: 問題ごとに、全員の回答を10の区間に分けた横棒グラフ。自分の回答・正解・全体の平均がどの区間にあるかを色で示し、2つが同じ区間に重なったときは斜めのストライプにしています
- **1円単位のプロット**: 全員の回答を1円単位で数えた細い縦棒のグラフ。区間にまとめると消えてしまう「キリのいい数字に回答が集まる」様子まで見えます。なぞると、その位置の金額と人数が吹き出しで出ます
- **物価推移**: 小売物価統計調査の年平均価格の推移を、最長で1950年から2025年まで折れ線で見せます。自分の答えが「何年ごろの値段」なのかが分かります

3つの面は、問題ごとのカードの高さを揃えてあります。横にスライドしても、同じ問題が同じ高さに来るので、面を行き来しながら1つの問題を見比べられます。各問題の下には、その値段の背景を短く解説するコラムも付けています。

## 中身の話

画面は React と Vite で作ったシングルページのアプリで、Cloudflare Workers から配信しています。出題・採点・集計の API は Hono で書き、同じ Worker の上で動かしています。回答のログと問題ごとの集計は Cloudflare D1（SQLite）に保存します。

静的なファイルはすべて Workers の静的アセットとして返し、`/api/` で始まるリクエストだけが Worker のコードに届く設定にしています。画面を開くだけなら Worker は起動しません。

### カンニングをさせない

クイズである以上、答えが手元で見えてしまっては意味がありません。正解の値段も、正解のヒントになる値（過去の価格や世間の平均）も、**回答を送るまではブラウザに渡さない**ようにしています。採点はすべてサーバー側で行い、100問分のマスターデータはブラウザに配るプログラムに含めていません。

### 集計を汚させない

全員の回答を見せるサービスなので、打ち間違いやいたずらの値がそのまま平均に入ると、グラフが崩れてしまいます。世間の平均・最低値・最高値は、正解の5分の1から5倍の範囲の回答だけで出しています。回答を送る API も、問題の ID・重複・金額の範囲を確かめてから受け付けます。送信は接続元ごとに1分6回までに制限しています。

### 見た目

見た目は、イラストレーターの unpis さんのサイトのような、生成りの紙の背景に均一な黒い線を引いた、ミニマルなイラスト調を目指しました。影は使わず、差し色は朱赤・緑・黄・青の4色だけ。数字の色とグラフの棒の色を必ず揃えて、どの数字がどの棒なのかを迷わないようにしています。絵文字は、画面にもシェアの文面にも一切使っていません。

結果は X にポストしたり、テキストでコピーしたりできます。
