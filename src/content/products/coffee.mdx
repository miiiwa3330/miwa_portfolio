## 「白い方眼の世界」にある、一人称3Dコーヒースタンド

coffee（`coffee.miiiwa.com`）は、Miiiwa の個人開発やものづくりを、カフェで飲み物を 1 本差し入れする感覚で応援できる個人専用のサポートサイトです。

一般的な投げ銭サイトのようにフォームに金額を入れて決済ページへ飛ぶのではなく、**「白い方眼の世界」に立つ青い自動販売機から飲み物を買い、隣に立っている手描きの猫キャラクター（miiiwa）へ自分の手で差し出す**、一連の一人称 3D 体験として作っています。画面の遷移を挟まずに購入から手渡し、お礼のやり取りまでを同じ空間の中で完結させています。

## 全7ショットの自販機体験と手描きの猫キャラクター

ページを開いた瞬間から、街路灯と青い自動販売機、そして隣に立つ猫キャラクターが見えます。自販機をクリックすると体験が始まり、全 7 つのカメラショットが連続して進みます。

1. **俯瞰から接近**: 足音と歩行の揺れを伴いながら自販機の前へ歩み寄ります
2. **投入口へフォーカス**: 硬貨・IC リーダーのあたりに寄った状態で決済手段を入力します（実際の決済なしで動きを試せるデモコインも用意しています）
3. **20 セレクションから選ぶ**: サントリーのスタンダードタイプ 20 セレクション機（幅 1,030mm × 奥行 660mm × 高さ 1,830mm）を参考に作り込んだ見本窓と押しボタンから、好きな飲み物を 1 つ押します
4. **排出と持ち上げ**: 取出口のフラップの内側に商品がガコンと落ち、カメラが下を向いたあと、飲み物が手元へ持ち上がります
5. **振り向きと手渡し**: 飲み物を持ったまま隣の猫キャラクターの方へ振り向き、上方向へのスライドまたはクリックで放物線を描いて渡します
6. **喜びとコースター発行**: 猫が飲み物を受け取って喜びの反応を見せ、応援の記録としてシリアル番号入りのデジタルレシート／コースターが発行されます。このタイミングで、任意でニックネームと応援メッセージを残せます

自販機に並んでいるのは、ブレンド・エスプレッソ・カフェラテ・コーヒー豆・メロンソーダ・コーラ・エナジードリンク・コーンポタージュの全 8 種類（¥150〜¥3,000）。温かい飲み物には湯気が出るなど、見本と実物のパッケージもそれぞれ作り分けました。

隣の猫キャラクターは、紙にペンで描いた 37 種類のポーズをそのまま切り抜いて 3D 空間に立たせています。線の外側に細い白フチを残したシール状の切り抜きにしており、腕と胴の間など線に囲まれた背景は抜きつつ、耳先のように線が閉じきっていない箇所は中が透けないように計算で埋めています。滑らかに 3D 変形させるのではなく、1 秒間に 12 回だけ線をわずかに揺らすパラパラ漫画（ライン・ボイル）にすることで、「二次元の絵が立体物の横にそのまま立っている」質感を狙いました。待機中には居眠りや小芝居をし、つつくと驚いたり照れたりといったリアクションを返します。

## 白い方眼の世界と実写感の両立

背景は、紙の上に方眼を引いたような明るいスタジオ空間です。自販機の本体はウェザリング（足元の泥はねや雨だれ、ガラスの指紋や硬貨口の擦り傷）と環境マップによる映り込み、GTAO（隙間の陰影）、被写界深度、FXAA を組み合わせて質感を出しています。一方で、白い紙の地面と背景が ACES Filmic トーンマッピングで灰ばんでしまわないよう、狙った白さと方眼線の色が出るように入力値を逆算して与えています。また、手前の自販機まで白く霞まないよう線形フォグを 10〜70m の範囲に限定し、猫の紙の色は背景よりわずかに暗くして輪郭を際立たせました。

また、端末の性能差で重くならないよう、フレーム時間を計測して処理負荷が高い場合は AO・被写界深度・描画解像度を段階的に落とす自動品質調整（tier 3 → 0）と、キャラクター画像の GPU 常駐枚数を直近 18 枚に抑えるキャッシュ制御も入れました。

## Stripe Payment Element と Cloudflare 単一構成

決済には Stripe の **Deferred Payment Intent（Payment Element）** を採用しています。自販機の投入口にカードを登録したあと、あとから押した商品ボタンに応じて金額を確定して決済を実行する順序が、日本の自販機の「お金を入れてからボタンを押す」操作感と一致するためです。決済時には Stripe の決済手数料（3.6%）を支援者側で上乗せして負担できるチェックボックスも備えています。決済完了時にシリアル番号付きの記録を保存し、Canvas のベクター描画による PNG コースターの保存や X へのシェア、`/receipts/:serial` での動的 OGP 表示、公開応援ボードへのメッセージ掲載に対応しています。

システム全体は React + Vite + Three.js のフロントエンドと Hono ベースの API を単一の Cloudflare Workers + Cloudflare D1 プロジェクトにまとめ、決済や個人情報の処理は Stripe に委譲して、自前のデータベースには公開応援ボードとコースター記録（`supports` テーブル）だけを保持する最小構成にしています。
