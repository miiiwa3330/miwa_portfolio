# sandbox — 動く試作物の置き場

本番サイトには載せないが、git には残しておきたい試作物の置き場。**単体で開ける HTML** が基本で、Next.js のビルド対象には一切入らない。

**`public/` に置かないこと。** このサイトは `output: 'export'` の静的書き出しなので、`public/` の中身は**そのまま公開 URL になる**。試作ページを置くと誰でも取得できてしまう。

**`src/**/*.test.ts` の Vitest とは無関係。** ここは自動テストではなく、目で見て判断するための実験場。2026-09-16 に `docs/prototypes/` から移した（`docs/` は書かれた記録を持つ場所であって、動く成果物の置き場ではないため。経緯は [docs/structure.md](../docs/structure.md)）。

動かすときは `python3 -m http.server` などで配信してから開く。`file://` で直接開く経路は確認していない（importmap で読む CDN モジュールの解決がブラウザによって変わりうるため）。
